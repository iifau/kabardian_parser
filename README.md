# kabardian_parser
## О дробных числительных:
Знаменатели есть 1-19 и десятки (20, 30, ..., 90), так как из каждого из этих семейств хотя бы одна засвидетельствованная форма была. Про остальные неизвестно. Есть маленькая вероятность, что n / 12 генерируется неверно, а как генерируется n / 18 и правильно ли это -- пока неизвестно, ждём информации. Числители 2-9, так как только для таких были свидетельства.
