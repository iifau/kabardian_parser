# kabardian_parser
## О дробных числительных:
Знаменатели есть 1-19 и десятки (20, 30, ..., 90), так как из каждого из этих семейств хотя бы одна засвидетельствованная форма была. Про остальные неизвестно. n / 12 генерируется по аналогии, n / 18 уточнили у носителя. Числители 2-9, так как только для таких были свидетельства.
## О дистрибутивных числительных:
Для вариантов через дефис типа щэ-зэрыз в первой части сто, тысяча, миллион, во второй --- числительные 1-10, хотя, возможно, формы типа "19 миллионов" тоже могут так образовываться.
